# Bank Management System

A console-based Bank Management System developed using C++.

## Features

- Create Account
- Deposit Money
- Withdraw Money
- Check Balance
- File Handling
- Object-Oriented Programming

## Technologies Used

- C++
- OOP Concepts
- File Handling
- Console Application

## Project Description

This project is a console-based Bank Management System that simulates basic banking operations such as creating an account, depositing money, withdrawing money, and checking the account balance.

Customer account details are stored using file handling.

## How to Run

1. Open the C++ source file.
2. Compile the program using a C++ compiler.
3. Run the program.
4. Select the required option from the menu.
